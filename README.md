# HomeFlow Web / GitHub Pages

This is the browser/PWA conversion of the HomeFlow desktop app.

## Deploy
1. Create a GitHub repository.
2. Upload all four files.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Open the GitHub Pages URL on a phone.
5. Use the browser's **Add to Home Screen** / **Install app** option.

Data is stored locally in the browser with localStorage. The app works offline after the first load.
